# Test fixtures

- **`example_expr_200.tsv`** — the public upstream 200-subject example expression
  matrix from `perou-lab/PAM50_classifier/PAM50_example/sampleInputFile_200subjects.txt`
  (the clinical `T` row dropped, leaving the 50 PAM50 genes × 200 samples).
  Subject to the upstream perou-lab licence (see `../../../vendor/perou-lab/PROVENANCE.txt`).
- **`expected_pam50scores_200.tsv`** — frozen output of `predict_pam50(expr,
  calibration = NA)` on the above. Generated by this package *after* it was
  verified byte-identical to the production bcarc_wts pipeline on real (not
  committable) patient data (225 samples, all calls + numeric columns identical).
  Serves as a regression guard against future changes to the port.
- **`synthetic_expr.tsv` / `synthetic_samples.tsv` / `expected_zhao.tsv`** — a
  small deterministic (`set.seed(42)`) synthetic fixture for `zhao_center`.

No real patient data is committed.
